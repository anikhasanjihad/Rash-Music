## About

Rash Music is a customised build based on the open-source
[Echo Music](https://github.com/EchoMusicApp/Echo-Music) project by iad1tya and contributors.
All original features are kept; branding, icon and developer information are AHR's.

## Updates (inside the app)

Every push to `main` builds the APK on GitHub Actions and publishes a GitHub Release (`vX.Y.Z`) with
`RashMusic.apk`. The app checks the latest release on start; when a new one exists it shows an update
dialog and downloads + installs it inside the app.
